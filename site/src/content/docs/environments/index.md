Agent 的表现高度依赖执行环境。相同提示词在不同文件系统权限、网络权限、shell、CI、浏览器状态下会呈现完全不同的能力边界。

## 环境维度

- 本地开发：用户文件、已有 git 状态、私有依赖、系统工具。
- CI：干净环境、可复现构建、缺失 secrets、固定权限。
- 容器：隔离更强，但调试成本更高。
- 浏览器：登录态、扩展、cookie、当前页面状态。
- 远程执行器：异步任务、日志回传、资源限制。

## 记录模板

每个环境说明都应该包含：

- 可读写范围
- 网络权限
- 可用命令
- secrets 来源
- 失败恢复方式
- 审计日志位置

## 后续组件想法

- Environment matrix：比较本地、CI、容器、远程执行器的能力。
- Sandbox simulator：切换权限组合，看哪些工具会被允许或阻止。
