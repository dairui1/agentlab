02

一段历史，有两种‘还在’

记录里还在，不代表模型当前看得见。

磁盘历史负责追溯；模型当前上下文负责下一步推理。压缩可以保留旧记录，同时把模型输入换成摘要和少量近期内容。

摘要可能遗漏约束。压缩流程结束只是技术终态，重要事实有没有保住，要另做检查或从稳定来源重新注入。

审计历史和当前模型输入，不能画成同一份列表。

05

真正不能忘的东西，别只靠摘要

把长期约束放进可重建的来源。

接口约束、目标、已确认结论和未决问题应从文件或结构化状态重新读取。摘要帮助延长对话，不该成为唯一账本。

恢复时分别核对：压缩有没有发生、当前输入用了哪个 replacement、任务有没有继续，以及关键约束能否从稳定来源找回。

摘要是工作记忆，不是完整档案。

先看现在实际发送给模型的内容，再讨论它为什么忘了。

教学窗格不是模型预算测量；摘要保真度和故障恢复仍要真实实验。

CMP-CX-01 · 90% 自动阈值不等于 95% 硬上限

`auto_compact_token_limit` 缺省取 resolved context window 的 90%，可用硬上限另按默认 95% 计算；触发量基于活跃窗口的 last usage 与本地估算，不是公开累计 `total`。

`last.totalTokens` 最接近触发量但仍非精确预测；模型目录可动态下发，不能硬编码具体 token 数。

CMP-CX-02 · 自动压缩有 turn 内与下一 turn 两个时机

需要 follow-up 或存在 pending input 时可在当前 turn 内压缩；终态回答越线则推迟到下一 turn，并在新 user input 写入 history 前执行。

下一条大输入不进入 pre-turn summary request，仍可能在检查后把正常请求推过上限。

CMP-CX-08 · 压缩安装为 replacement checkpoint

成功压缩把完整 replacement history 与 window metadata 持久化为 `RolloutItem::Compacted`；resume 从最新有效 checkpoint 重建 active history，而原 rollout 前缀仍留在存储中。

审计 transcript 仍能看到旧 turn，不表示模型在新窗口中仍能看到它们。

CMP-CX-09 · PostCompact 停止不会回滚 replacement

PostCompact hook 在 replacement 安装、token 重算与 item completed 之后运行；hook Stop 可令最终 turn interrupted，但不会撤销新 history。

harness 必须允许“compaction item completed + turn interrupted”同时成立，不能把 turn 状态当事务结果。

CMP-CX-10 · 模型切换本身可以触发压缩

前后模型的 `comp_hash` 不同，或切换到更小窗口且当前活跃 usage 超过新限制时，Codex 会在新 turn 采样前尝试用旧模型压缩。

任一 hash 缺失时不因 hash 触发；旧模型失败后的 fallback 只覆盖特定 backend/provider/error 组合。

CMP-OC-04 · marker 与 summary 留在持久 transcript

每次压缩写入带 `auto` / `overflow` 的 compaction marker 和 `summary:true` assistant message；模型投影从最新成功 boundary 重建并隐藏被覆盖旧 history。

存储中仍可查到旧内容，不表示后续模型能看到它，也不等于删除或隐私清除。

CMP-OC-05 · recent tail 是预算内目标，不是两轮保证

默认尝试保留最多两个近期 user turns，并用 `clamp(usable*25%, 2k, 8k)` 控制尾段预算；算法可按消息边界缩短或不保留。

这两个字段只在 schema 中暴露，未进入固定版本的公开 config 文档，兼容性应降级标注。

CMP-OC-06 · summary 输入先做有损扁平化

CMP-OC-07 · prune 默认关闭且不在 summary 前执行

`compaction.prune` 默认 false；启用后只给旧 completed tool parts 写 compacted 标记，并在 session loop 退出后异步执行。

原 output 仍在存储，active projection 才替换为 placeholder；prune 不能为同一次 summary request 预先降载。
